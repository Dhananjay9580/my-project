docker — zero se shuru

Docker ko bilkul basic se samjho

Ek container shipping yard ki tarah — har application apne isolated box me packed hoti hai, apni dependencies ke saath, kahin bhi same tarah chalne ke liye. Yahan se shuru karo.

01

Docker kya hai?

Docker ek tool/platform hai jo application ko ek isolated environment — yaani container — ke andar run karta hai.

Aapke laptop par Python version, libraries aur configuration alag hain, aur kisi doosre computer par alag. Docker application ke saath uski required dependencies ko package karke same environment me run karne me help karta hai.
02

Container kya hai?

Container = application run hone ka isolated environment. Containers lightweight hote hain, aur ek hi machine par multiple containers ek saath run ho sakte hain.

your laptop
Your Laptop
  └── Docker
        ├── Container 1  →  Python App
        ├── Container 2  →  MySQL
        └── Container 3  →  Nginx
03

Docker Image kya hai?

Image ek template/package hoti hai jisse container create hota hai.

Docker Image
↓
Container
↓
Running Application

Pehle Python ki image download karo:

terminal
docker pull python

Phir usi image se container run karo:

terminal
docker run python

04

Docker Hub kya hai?

Docker Hub ek public registry hai jahan Docker images available hoti hain — hub.docker.com.

terminal
docker pull nginx

Docker Hub se nginx image download ho jayegi.

06

Port kya hota hai?

Suppose Docker container ke andar web application port 80 par chal rahi hai. Aap apne laptop ke port 8080 ko container ke port 80 se connect kar sakte ho:

terminal
docker run -d -p 8080:80 nginx
8080
laptop
80
container

Browser me http://localhost:8080 open karoge to Nginx application dikhegi.

07

Dockerfile kya hai?

Dockerfile ek file hoti hai jisme hum define karte hain ki apni application ki Docker image kaise banani hai.

Dockerfile
FROM python:3.12

WORKDIR /app

COPY . .

RUN pip install -r requirements.txt

CMD ["python", "app.py"]

Image build karo:

terminal
docker build -t myapp .

Phir container run karo:

terminal
docker run myapp
